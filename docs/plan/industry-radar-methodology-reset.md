# 行业雷达 · 方法论重置方案

> 状态：**草案 v1** · 生成 2026-10-13 · 定位：先解决"方法"，再谈"工具"
> 一句话背景：当前行业雷达的产出几乎全部建立在**价格/成交结构**上，而这一维度已被本项目
> 自身的事件研究**系统性证伪**。本文提出"景气-估值-拥挤"的新方法框架，并以一个**最小验证实验**
> 作为第一刀。

---

## 0. 为什么要重置（诊断）

### 0.1 现状一句话

雷达每天对用户说：**"注意力很高、但都在亏钱、且没有任何主线"**，再补一句"以上均无预测力"。
三个章节（主线状态 / regime / 链共振）互不整合，无综合判读，无 watchlist，无前瞻层。

### 0.2 根因：方法在"价格结构"里走到了头

本项目用严格的事件研究（按日聚类 t、IS/OOS、中位数 vs 均值）已经**证伪**了几乎所有量价维度的预测用途：

| 已证伪 | 证据要点 |
|---|---|
| 资金流（主力/超大单净流入） | 价格滞后跟随，IC 反向 |
| 拥挤度（换手率） | 对未来 \|t\| 全 < 2 |
| 动量 / 低波 / 技术突破 / 质量 / 成长 | IC≈0 或反向 |
| 量价确认（放量上涨做多） | 行业层面 IC 为负 |
| 宽度反转 / 反转跟踪池 / 状态机 | 全部证伪 |
| **主线探测（当前主信号）** | **语义基础已证伪**：判据依赖成交额热度，成交额滞后于价格 |

**结论：不是工程没做好，是在一个已被证伪的维度里反复挖掘。**

### 0.3 根本原因：只吃了四类营养里最弱的一类

`indicator-status-register.md §5` 早已记录：**① 景气 ② 估值 ③ 资金 的原料全在 `~/quant-data`，
但九步链只读了 ④ 价格结构。**

行业（申万二级）是几十上百只股票的市值加权平均，其收益横截面由
**β（市场）+ 风格（大小盘/价值成长）+ 景气（盈利预期变化）** 驱动，
行业自身的量价形态残差信号极弱。行业轮动是**慢变量**（盈利/政策/产业趋势/估值）驱动，
却在**快变量**（量价）里反复挖掘 —— 方向反了。

## 0.5 第 0 步：论证"研究对象"（比景气验证更前置）

> 🔴 2026-10-13 主人提出、已确认：**"申万二级"作为研究对象是否合理，必须先论证**，
> 因为它决定后面所有工作的地基。景气验证、三因子框架都绑定在"对象"上，对象选错，结论全错。

### 0.5.1 为什么要质疑"申万二级"

1. 本项目多起证伪/事故，根因都指向**对象边界不稳**：方向群聚类聚出 beta 影子（58 行业巨群、
   250 日重聚保留率仅 47.3%）；产业链 74 条靠 ETF 篮子机械定义；单行业伪群（群14）也被判主线。
2. "申万二级"三个隐含问题：
   - **粒度**：131 个二级，很多太细（林业Ⅱ、航海装备Ⅱ），成分少、噪声大（链验证已见 n=2 链 5/9 验证失败）。
   - **稳定性**：申万调成分/改分类 ⇒ 边界漂移 ⇒ "用今天标签回测昨天"。
   - **可交易性**：多数二级无直接 ETF/指数，靠 ETF 篮子逼近，而篮子本身错配（TMT50ETF→银行）。
3. 更根本一层：要研究的是**"行业"还是"驱动行业的因子"**？若是后者，"申万二级"只是载体之一，
   可用一级/产业链/自定义因子分组替换 —— 对象应服务因子，而非反过来。

### 0.5.2 论证对象的四个判据（缺一不可）

1. **同质性**：组内股票收益驱动一致（剥 beta 后组内残差相关高且结构稳定）。
2. **稳定性**：边界随时间不漂（重聚/重组保留率高）。
3. **可交易性**：有直接或近似可投标的，映射漏损小。
4. **规模**：组内成分够多，噪声可控，横截面 alpha 有统计功效。

### 0.5.3 候选对象谱系（从粗到细）

| 候选 | 粒度 | 成分数 | 可交易性 | 同质性 | 数据 |
|---|---|---|---|---|---|
| 申万一级（31） | 粗 | 多 | 高（主流 ETF 齐全） | 中 | ✅ `sw_l2_to_l1.json` + `sw2021_industry_tree.tsv` |
| 申万二级（131） | 中 | 少（很多 <10） | 低 | 中 | ✅ 现用 |
| 产业链/主题（74 链） | 不定 | 不定 | 中 | 高（若定义对） | ✅ `chain-prior-list.csv` |
| 因子分组 | — | — | — | 高（按因子切） | 需自建 |

### 0.5.4 对象诊断设计（可立即执行，数据已核实可用）

**同质性**：对申万一级 / 二级 / 74 链，分别算"剥 beta 后组内残差相关"。
- 数据：`industry_residual_panel.parquet`（`date`+`ind_code`+`resid_raw`+`resid_adj`，208290 行，
  2020-03→2026-10）✅ 现成。
- 方法：`resid_adj`（再剥风格）是更干净的同质性度量。

**稳定性**：每个对象算重聚/重组归属保留率（250 日滚动，方向群已有 47.3% 基线可对比）。

**可交易性**：每个对象统计 ETF 覆盖率与映射漏损（`etf_industry_similarity` 系列）。

**规模**：每对象成分数分布（`sw2021_industry_tree.tsv` 已有 `n_members` 列 ✅）。

### 0.5.5 交付物

- `research/validate_object.py`：对象诊断脚本（同质性/稳定性/可交易性/规模四维）
- `docs/validation/对象论证报告.md`：结论 + 选定对象 + 依据

**决策点**：诊断后选定"研究载体"（一级 / 二级 / 链 / 因子分组），后续景气验证与三因子框架
都在该载体上做。

### 0.5.6 初步实测（2026-10-13，`research/validate_object.py` 已跑）

| 判据 | 二级(131) | 一级(31) | 链(74) |
|---|---|---|---|
| 同质性 A（行业内个股 r，**只剥β未剥风格**）| 均值 +0.354 / 中位 +0.321 | +0.317 / +0.273 | — |
| 同质性 B（组内行业 r，resid_adj）| —（单行业组无内部结构）| +0.322 / +0.316 | +0.276 / +0.243 |
| 规模（成分股中位，最小2）| 中位 28（25%分位仅13.5）| 34 | 69 |

⚠️ **caveat（未竟）**：
- 同质性 A 目前**只剥了市场 β，未剥风格** ⇒ 数字被风格共动污染、偏高，须补剥风格后重看。
- "二级 > 一级"（个股同质）符合直觉（越细越同质），但真正要回答的是**剥风格后**该差距是否仍成立，
  以及**二级里那批小行业（成分<15）是否拖累整体**。
- 同质性 B 显示：产业链(0.276) **低于** 一级(0.322) ⇒ 从"行业同向性"看，产业链并未比一级更同质。
  这与"链是更优对象"的直觉**相悖**，需重点复核（可能因为链是 ETF 篮子机械定义、含错配成员）。
- 稳定性、可交易性两判据**尚未测**。

## 1. 新方法框架：景气-估值-拥挤 三因子行业配置

这是国内公募/券商行业轮动研究里**最主流、最有实证支撑**的框架，核心一句话：

> **行业配置 = 找"景气向上 + 估值不贵 + 还不拥挤"的行业。**

| 因子 | 含义 | 数据源（已核实可用） | 角色 |
|---|---|---|---|
| **景气** | 盈利增长、盈利预期上修 | `financial_statements/income`（含 `ann_date`，可 PIT） | **主驱动** |
| **估值** | PE/PB 分位数 | `daily_basic/`（1636 天，18 列） | 衡量景气是否已定价 |
| **拥挤** | 换手分位、成交占比 | `factors/ind_crowd_turnover_daily.parquet` | **过滤器**（降权，非单独预测） |

⚠️ 关键区分：**拥挤度单独当预测因子已证伪**，但作为"景气好但太拥挤→不追"的**过滤器**是有实证的
独立用法，与本项目之前的"单独预测"是两回事。

### 1.1 优先级排序（可依次叠加的增量路线）

- **A（第一优先）**：景气 → 这是主驱动，先验证
- **B**：估值（PB-ROE 二维：低 PB + 高 ROE = 性价比洼地）
- **C**：拥挤（过滤器）
- **D（辅助层）**：产业链**基本面**传导（注意：用利润/景气在上下游的传导，**不是**现在用的"价格残差相关"）
- **E（辅助层）**：事件/资金异动告警（龙虎榜/大宗/股东户数/两融）

## 2. 第一步（最小验证实验）：景气这条腿到底有没有肉

### 2.1 要回答的问题（决定性）

> 行业层面的**景气变化**（盈利增速、盈利增速的变化），对未来 **1~3 个月**的行业超额收益，
> 有没有**可用**的前瞻预测力？

- 若**通过**：雷达有了真正的"发动机"，后续三因子框架 + 横截面排序 + watchlist 都有了根基。
- 若**不通过**：立刻知道该转向（估值？产业链传导？），而不是继续空转。

### 2.2 已验证的地基事实（本会话实测）

| 项 | 事实 |
|---|---|
| 财报 | `income/YYYY/QN/income_YYYYMMDD.parquet`，17 个文件，2020Q1→2026Q2 |
| 公告日 | `ann_date` **100% 非空**（可做 PIT，无前视） |
| 盈利字段 | `n_income`（净利润）、`n_income_attr_p`（归母）、`total_revenue`（营收）全可用 |
| 行业收益 | `industry_weighted_returns.parquet`：`date` + `ind_code` + `weighted_pct`（circ_mv 加权），2020-01-02→2026-10-13 |
| 成分映射 | `industry_members_daily.parquet`：`date` + `ind_code` + `stock_code`（844 万行） |
| ⚠️ 代码格式 | 成分表 `stock_code` 是富途格式 `sh.600679`，财报 `ts_code` 是 Tushare 格式 `600679.SH`，**需转换对齐** |

### 2.3 验证设计（草案，需按项目采纳门槛落地）

**核心变量：**

1. **景气指标**（个股→行业聚合，PIT）：行业净利润同比增速、营收同比增速、以及增速的**环比变化**（景气加速度）。用 `ann_date` 做 PIT：在交易日 t，只能用 `ann_date ≤ t` 的财报。
2. **因变量**：行业未来 h 日超额收益（h ∈ {20, 40, 60}），超额 = 行业收益 − 全行业等权均值。

**检验方法（复用项目既有采纳门槛）：**

- 事件研究或横截面 IC / 分组单调性；
- 按日聚类 t（防重叠相依观测）；
- IS/OOS 双显著；
- 同时报中位数与均值（防尾部效应）；
- 分组：按景气分位分 5 档，看 Q5−Q1 超额单调性与显著性。

**关键细节（防重蹈覆辙）：**

- PIT：严格用 `ann_date`，禁止用 `end_date`（否则前视）。
- 财报覆盖滞后：`end_date=2026-06-30` 的财报，`ann_date` 落在 2026-08-22 之后。验证时该财报只有在 `ann_date` 之后才"可见"。
- 行业聚合口径：个股净利润 → 行业汇总。注意**少数个股财报缺失**的处理（用已有成分聚合，不填 0）。
- 金融行业（银行/券商）的利润口径特殊，可能需要单独处理或排除。

### 2.4 交付物

- `research/validate_prosperity.py`：景气 PIT 构建 + 验证脚本
- `docs/validation/景气前瞻力验证报告.md`：IC / 分组单调性 / IS-OOS / 中位数 vs 均值 / 结论
