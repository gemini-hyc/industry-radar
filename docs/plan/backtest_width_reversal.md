# 宽度反转因子回测方案

> 创建：2026-07-25
> 目标：对小克设计的宽度反转因子进行条件因子回测，验证其预测力

---

## 一、为什么不能用截面IC？

截面IC的全流程是：每天131个行业全量排名 → 看排名和未来收益的相关性。

宽度反转因子是**条件因子**：
- 触发条件：前20日均宽 ≤ 30% + 连续扩张 ≥ 3天
- 信号稀疏：日均0.4~1.1个（≥5分档），覆盖不到5%的行业×日期
- 截面IC把95%无信号的样本拉进来算相关，结论注定≈0

正确的回测方法是：**只在信号触发时统计超额收益**，类似临床试验——只有服药的病人才能评估疗效。

## 二、回测框架设计

### 2.1 因子定义（与小克方案严格一致）

**宽度定义**：行业内当日上涨个股占比 `(pctChg > 0).mean()`，即涨跌占比宽度。

此定义与小克 `ic_analysis_5factors.py` 第180行的定义一致，也与 `scripts/backtest_width_reversal.py` 中 `compute_industry_breadth()` 的实现一致。

**触发条件**：
- 前20日均宽 ≤ 30%（bw20 ≤ 0.30）
- 连续扩张 ≥ 3天（当日宽度 > 前一日宽度，持续3天以上）

**质量评分**（总分2-10）：

| 维度 | 计算方式 | 得分 |
|:---|:---|:---|
| 基础分 | 触发即得 | +1 |
| ①前20日均宽 | 扩张前20日宽度均值 | <10%:+3, <20%:+2, <30%:+1 |
| ②首日力度(D1占比) | d1/(d1+d2+d3)，扩张首3天各日宽度增幅的占比 | ≥60%:+3, ≥50%:+2, ≥40%:+1, <40%:+0 |
| ③放量(三日量比) | 扩张前3天日均成交额 / 前20日日均成交额 | ≥1.3:+3, ≥1.1:+2, ≥1.0:+1, <1.0:+0 |

**信号分级**：≥3分（观察）、≥5分（标准）、≥7分（高置信）

### 2.2 回测方法——事件驱动回测

核心思路：每次信号触发时，记录触发日和触发行业，然后统计该行业在触发后N日的收益表现。

**步骤**：

1. **数据准备**
   - 加载全市场日线行情（2020-01 ~ 2026-06，覆盖牛熊震荡三段）
   - 行业成员映射（131个申万二级行业）
   - 对每个行业，计算每日 breadth（当日上涨个股占比 `(pctChg > 0).mean()`）

2. **信号扫描**
   - 逐日遍历每个行业，检测是否满足触发条件
   - 满足则计算质量评分，记录信号

3. **收益计算**
   - 每条信号触发后，计算该行业的未来5日/10日/20日收益
   - 行业收益 = 成分股等权平均涨跌幅
   - 基准收益 = 全市场等权平均涨跌幅（同时间段）
   - 超额收益 = 行业收益 - 基准收益

4. **统计汇总**
   - 按得分档（≥3/≥5/≥7）分组统计
   - 每组计算：日均信号数、平均超额、胜率、IR
   - 分时间段验证稳定性（2020-2021结构牛 / 2022-2024震荡熊 / 2024后政策牛）

### 2.3 关键设计细节

**重复信号处理**：
- 同一行业在宽度持续扩张期间，可能连续多天满足触发条件
- 处理方式：同一行业的连续信号只取**首次触发日**，后续扩张日不重复记录
- 下次可记录的条件：宽度回落到 ≤30% 后再次连续扩张 ≥3天

**前视偏差防控**：
- 未来收益用 shift 计算，不提前取数
- 宽度计算基于当日 pctChg，无需滚动窗口，无前视风险
- 评分只用触发日及之前的数据，不看未来

**涨跌停分板块**：
- 主板：9.8%
- 科创板/创业板：19.5%
- 北交所：29.5%
- ST：4.8%
- 过滤时剔除ST，但不剔除科创板和北交所（全市场对齐）

**行业收益计算**：
- 等权平均涨跌幅（与小克方案一致）
- 不用市值加权（避免大市值行业主导结果）

**基准收益**：
- 全A股等权平均涨跌幅（同时间段）
- 不用沪深300或中证全指指数收益（指数是市值加权的，和等权行业收益不对齐）

## 三、与小克IC回测的本质区别

| | 小克的方法 | 本方案 |
|:---|:---|:---|
| **方法类型** | 截面IC | 事件驱动 |
| **样本范围** | 全行业全时段 | 仅信号触发时 |
| **评价对象** | 因子值排序的预测力 | 信号触发后的超额 |
| **对照基准** | 无（只看IC绝对值） | 随机对照组（冷区同等池） |
| **维度** | 截面相关系数 | 超额收益/胜率/IR/分阶段 |
| **信号稀疏性** | 不考虑 | 首次触发不重复 |
