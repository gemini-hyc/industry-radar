## 2. 🔴 本轮核心：病因是**风格**，不是"链跨了一级"

### 2.1 K 存活率实测（AI 新增；研究员只测了跨 L1 子集）

对残差面板做 SVD，投影剔除前 K 个主成分，看基线 217 对里哪些还活着，**按 L1 内外分开**：

| K | 全样本 \|r\|≥.40 | **同 L1 存活率** | **跨 L1 存活率** |
|---:|---:|---:|---:|
| 0 | 217 | 100% | 100% |
| **1** | 113 | **74%** | **27%** |
| 2 | 76 | 57% | 11% |
| 3 | 53 | 38% | 10% |
| 4 | 41 | 31% | 6% |
| 6 | 24 | 20% | 2% |

**同 L1 存活率在每个 K 上都是跨 L1 的 2.5~5 倍。**

### 2.2 由该表推出的两个结论

**结论 A（证实研究员）**：`within-L1` 限制之所以能"提高稳定性"（47.3% → 92.5%），
**主因是风格块跨一级、限制在一级内部就把大部分风格共同暴露挡掉了** ——
它是**一个粗糙的风格过滤器**，而不是"产业链多在一级内部"这一经济学命题的证据。

⇒ 一旦有了正规风格控制，`within-L1` 就失去存在理由：这正是"两处修法必须同时上"的正确性来源。
⇒ **只放开限制而不做风格控制，会把约 80 个风格对当成链收进来，比现状更糟。**

**结论 B（他与我此前都漏了）**：**现有 167 对本身也有风格污染** ——
K=1 时同 L1 只剩 **74%**（≈26% 是风格）、K=3 只剩 38%。
⇒ **"167 对稳定 / 77%" 这个被写进文档、并用来支撑"限定一级"设计决策的数字，
其风格污染率从未被度量过，须一并重算。**（即 §8 修订 7）

### 2.3 特征值谱：**无肘部**（这是 §5 判定的关键）

```
前 8 个主成分占比: 11.9 / 8.4 / 5.8 / 4.5 / 3.1 / 2.4 / 2.4 / 2.3 (%)
存活率曲线:        50% → 34% → 24% → 18% → 16% → 11%
```

两条曲线**都是平滑衰减、没有拐点** ⇒ **K 无法客观确定**（详见 §5）。

## 3. 关于 **0.30 阈值**的裁定（应主人要求单列）

### 3.1 作为「水平下限」：**合理**

| 参照 | 0.30 的位置 |
|---|---|
| 各段 r 的噪声 SE（486/484/666 日） | 0.045 / 0.045 / 0.039 ⇒ 0.30 ≈ **6.7σ** |
| 剥 beta 后的**背景水平**（文档自己的"杂货袋"级别：轻工 0.083 / 家电 0.107 / 商贸 0.116） | 0.30 ≈ **2.5~3.6×背景** |

⇒ 作为"这个相关不是噪声"的门槛，**0.30 保守、可靠，没有问题**。

**而且它的「拒绝侧」是干净的**：被判不稳的 50 对里，**段间极差 < 0.10 的有 0 对** ——
**它没有误拒任何一对本该通过的**。问题全在"接受侧"。

### 3.2 作为「稳定性判据」：**用错了工具**

0.30 是**用一个"水平门槛"去回答一个"离散度问题"**。三个量化缺陷：

#### ① 它接受剧烈摆动的对

| 过了 0.30 却被判"稳" | 三段 | 极差 |
|---|---|---:|
| 汽车零部件 ↔ 家电零部件Ⅱ | 0.33 / 0.59 / 0.75 | **0.42** |
| 消费电子 ↔ 通信设备 | 0.32 / 0.59 / 0.71 | **0.39** |
| 计算机设备 ↔ IT服务Ⅱ | 0.33 / 0.69 / 0.72 | **0.39** |
| 房地产开发 ↔ 房地产服务 | 0.43 / 0.74 / 0.76 | 0.33 |

**167 对"稳定"里，44 对极差 > 0.20。** 而两段差的噪声标准误仅 **0.064**
⇒ **极差 ≤ 0.13 才算"噪声内一致"**；**217 对里只有 66 对（30%）满足**，极差中位数 **0.18（≈2.8×噪声）**。

#### ② 37% 的"稳定对"其实是"闪烁"

| 形状（噪声基准 0.13） | 对数 | 含义 |
|---|---:|---|
| **平坦**（极差 ≤0.13） | 66 | 真·结构 |
| **单调递增** | 77 | 文档所称"产业演化/新生真链" |
| 单调递减 | 21 | 衰减中的关系 |
| **闪烁**（非单调、非平坦） | **84** | 无一致水平 |

**其中「闪烁」却在 ≥0.30 下被判"稳"的有 62 对（占 167 的 37%）** —— 如 `[0.31, 0.60, 0.31]`
这种"上去又下来"的形状，**三段都过 0.30，但没有稳定水平**。这是 0.30 规则最实质的漏网。

> **工具与语言不匹配**：文档在实测四里**已经用了三分类的语言**（"不是假货，是产业演化"），
> 却用了一个**二元门槛**去实现它。

#### ③ 阈值无理论锚点，且**论据随它漂移**

| 判稳门槛 | 判稳对数 | 同 L1 占比 | 跨 L1 稳定对 |
|---:|---:|---:|---:|
| 0.20 | 200（研究员 201） | 50% | 100 |
| 0.25 | 191 | 52% | 92 |
| **0.30** | **167（研究员 170）** | **54%** | **76（研究员 78）** |
| 0.35 | 134 | 60% | 54 |
| 0.40 | 100（研究员 103） | 72%（研究员 71%） | 28 |

- **无平台**（200→191→167→134→100 平滑衰减）⇒ 边界上的分类是任意的；
- 论证"共振多在一级内部"的 **54% vs 34%** 这一论据，在 0.40 下会变成 **72% vs 31%**
  ⇒ **换一个门槛，论据就换一个样子**。

### 3.3 它有一个**可辩护的读法**，但文档没写出来

`0.30 / 0.40 = 0.75` ⇒ 这条规则的**真实含义很可能是「允许回落到选对门槛的 75%（即允许 25% 回落）」**。
这个读法**合理**（噪声量级上，0.10 的下降 ≈ 1.6×两段差标准误，勉强算"没变"）。但必须以**相对规则**写出：

```
选对：全样本 |残差 r| ≥ θ
判稳：三段 |r| ≥ 0.75·θ          ← 而不是硬编码 0.30
```

否则：① 读者无法从"167/77%"反推出 0.30（AI 就是这样先得到 46% 的）；
② 一旦有人把选对门槛改成 0.30，判稳门槛就退化成"min ≥ 选对门槛"、规则失效。

### 3.4 **不可移植性**（与 §5 的修法直接冲突）

0.30 是在**「只剥市场 beta」的残差**上标定的。一旦按 §5 采纳**风格因子回归**，
残差相关的整体水平会下降 ⇒ **0.30 必须重新标定，不能沿用**。
⇒ 现在的 0.30 是**绑定在当前这版残差定义上的经验数**，不是可迁移参数。

### 3.5 裁定

> **保留 0.30 作为水平下限，但必须三改**：
> ① 明写为**相对规则** `min ≥ 0.75·θ`；
> ② **增加离散度判据**（极差 ≤ 2×SE_diff ≈ 0.13）；
> ③ 用**三分类（结构/新生/闪烁）**替代二元门槛（§4）；
> ④ 采纳风格回归后**重新标定**两个阈值。

## 4. 三分类设计（替代二元门槛）

| 类别 | 判据 | 处置 | 本批数据（217 对） |
|---|---|---|---|
| **结构** | **Cochran Q 同质性检验 p > 0.05**（Fisher-z，df=2） | 收入链核心 | **45** |
| **新生** | 不同质 **且** 严格单调递增（在 z 上）**且** 每级增量 > 自身 SE | 入"观察中"，**不转正** | **33** |
| **衰减** | 不同质 且 严格单调递减 | 拒 | 12 |
| **闪烁** | 其余（非单调、无一致水平） | 拒 | 127 |

**⚠️ 本表已由"拍系数版"升级为"检验版"**（2026-10-06 第三轮，见 §11.2）。
**关键是锚在零分布上，而不是锚在门槛上**：

- **结构 45 对 vs 纯噪声期望 11 对**（5% 水平）⇒ **超额 34 对 = 真正的结构证据**；
- "新生"目测单调 77 对 vs 噪声期望 217/6 ≈ 36 对 ⇒ 超额 41 对；
- df=2 时卡方生存函数有**精确闭式 `P(Q>q)=exp(−q/2)`** ⇒ 实现仅数行、**不需要 scipy**；
- 每级噪声锚点 `SE(Δz)=√(1/wᵢ+1/wⱼ)`，`w=n−3` ⇒ 实测 **0.06**（不是拍的）。

⇒ 该口径下"真·结构"**45 对**（占选中 217 的 21%、占全部 8,515 对的 **0.5%**）——
比"167 对稳定（77%）"**诚实得多**。
❌ **旧口径（极差 ≤0.13 → 67 对）偏松**：其中 **22 对被 Q 判为不同质**；旧计数 66/77/84+21 **一律作废**。

**并且它顺带解决了文档的一个内在矛盾**：文档把 `[0.2,0.6,0.7]` 判为"真链但新生"（想留），
又用 0.30 把它拒掉（留不下）；三分类里它自然落到"**新生**"这一格 —— **留而不转正**，
正好是文档想要的处置。

## 5. 风格控制的修法裁定：**弃 PC 投影，用可观测因子回归 + 群级零分布**

### 5.1 研究员 PC 版发现的价值

| 研究员实测 | 判定 |
|---|---|
| K=1：78 对只剩 19（24%）；K=3：只剩 7（9%） | ✅ 方向与我一致（我：K=1 跨 L1 存活 27%） |
| 死亡名单清一色风格聚类（房屋建设↔银行/保险/水泥/轨交、煤炭↔油气、半导体↔军工电子/通信设备、软件开发↔游戏/数字媒体） | ✅ 与我的存活率表一致 |
| 「锂电链死于 K=3」⇒ K 要保守、验证单位应当是**群** | ✅ **本轮最有价值的洞察**（见 5.3） |

### 5.2 但 PC 投影**与 0.30 是同型病**

| 缺陷 | 说明 |
|---|---|
| **无肘部 ⇒ K 无法客观确定** | 谱与存活率曲线都平滑无拐点（§2.3）。**0.30 至少有"167/77%"这个可陈述产出；K 则是在无平台曲线上选一个点。** "K 要保守（1~2 起步）"正是"没有原则、只好保守"的自认 |
| **PC 不是风格** | 主成分是**统计因子、无经济身份**。`半导体↔通信设备` 从 0.49→0.20 就死 —— 它**可能是风格，也可能是真实的 AI 算力链**。PC 投影**无法区分"共同风格"与"共同产业主题"**，因为两者都表现为一个共同因子 |
| **一手削风格、一手削真链** | K 就是这个交换比率（锂电链即代价） |
| **违背本节自己的立场** | 文档原文护栏 3 写的是「**残差对风格因子二次回归**，量化共振中**不能用风格解释的份额**」= **有身份因子 + 连续份额**。PC 投影是**无归属权的黑箱**，与 §2.2「定义权/否决权/测量权」的整个方法论立场相悖 |

### 5.3 正解：可观测因子回归 + **群级零分布**

| 环节 | 具体做法 |
|---|---|
| **风格因子** | size（`daily_basic.circ_mv` 行业聚合）、value（PE/PB）、momentum（过去 20/60 日）、vol（已实现波动）、拥挤度（`ind_crowd_turnover_daily` —— **现成**） |
| **度量** | 残差对上述因子回归，**逐对报告"风格解释份额"（连续量）**，而非"存活/死亡" |
| **判决例** | `半导体↔通信设备`：回归后仍剩 0.3+ ⇒ 真链；归零 ⇒ 风格。**可解释、可判决** |
| **验证单位** | **群**（见下），不再以"对"为主 |

**群级验证的设计**（同时解决三个问题）：

```
群   = 语义定义的候选链（先验，来自 §2.2 的"定义权"）
统计量 = 群内平均 |残差 r|（或群级单因子载荷）
零分布 = 从 131 行业中随机抽"同样规模"的群，重复 2,000 次
判据  = 实际群内共振 > 零分布 95 分位
```

它同时解决：
① **无 K 选择问题**（不投影，直接测量群）；
② **无成对多重检验**（8,515 对的选样问题消失，群数只有个位到十位）；
③ **多成员真链不会被"吸收掉"**（测量对象就是群本身，锂电链的集体共振**正是信号而非要剔除的因子**）。

> ⚠️ **前提**：群必须**来自语义先验**。若改成"按群内共振最大化去搜群"，就退回了
> §2.2 明令禁止的"用共振划家族→再测家族共振"闭环。

## 6. 🔴 认识论警示：「7 对全过语义检验」**不能**作为方法背书

筛选流程是 `全样本 |r|≥0.40` → `三段稳定` → `风格剥离` → `看语义`。
⇒ 这三道筛子**本身就是"持久、高相关、非风格"的代理**，而"像产业链"是这些属性的**同义描述**。
**"7 对全过语义检验"近乎同义反复，不是独立证据。**

**正确的验证设计**（成本极低）：

1. **语义先**：先写下**事前**认为存在的链（锂电、银保、金饰、出行…），**不看数据**；
2. **跑方法**，测**命中率 / 漏检率**：这 7 对里有多少在事前名单？事前名单里有多少被漏掉？
3. 这才是"语义定义权 ∩ 共振否决权"的**真检验**。

### 11.1 🔴 裁决建议：测量层**不是"调或不调"的二选一**

研究员问：日频"测量权"的产物（共振强度连续量）要不要做风格调整？
他给了两个立场 —— (a) 不调整（"钱挤进这个方向"就是答案，哪怕因为风格）；(b) 调整（否则污染归因）。
**两个立场都不完整**，因为问题被表述成了"调不调"，而真正要裁决的是「**存什么、谁用哪个**」。

#### 核心技术论点（它决定了裁决方向）

> **调整后的共振是 `(原始共振, 因子暴露)` 的确定性函数；反过来不成立。**
> ⇒ **只存调整值 = 不可逆地丢信息。**
> ⇒ "该用哪个口径"是**消费层的选择**，不该在**存储层**被一次性烧掉。

#### 建议的裁决：三分

| 层 | 存 / 用什么 | 理由 |
|---|---|---|
| **存储层** | **原始共振 + 因子暴露** 两列同时落盘；调整值**派生**（也落盘便于直读） | 最小充分状态。日后换因子集/换窗口，**无需重跑历史**即可重算调整值 |
| **日报「状态描述」** | **原始值** | 它回答"**钱是否在往这个方向挤**"—— 风格驱动的一次流入**也是真实的资金迁移**，且**用户屏幕上看得见**。若日报用调整值，会出现"盘面明明在涨、报告说无共振"的直接打脸 |
| **研究 / 归因（景气×估值）** | **调整值** | 否则**风格 beta 被记成链信号** → 归因循环。这正是"167 对从未度量自己风格份额"的同一个坑 |

**➕ 强制项**：**把「原始 − 调整」的差额（风格解释份额）作为可观测量每日报告。**
理由：任何群的差额长期偏大 ⇒ 说明它的"共振"主要是风格 —— 这应当在**对象清单层被标注**，
**而不是在测量层被静默抹平**。**"不要静默处理"是本轮（乃至本项目）的核心教训。**

#### 研究员提的二阶问题（因子集必须同源）：**同源要由工程保证，不能靠约定**

不是让"测量层去迁就验证层"，而是：**建一个「风格因子面板」一等产物**
（登记 `src/paths.py:ARTIFACTS` + meta sidecar），**测量层与验证层都从它取**。
项目已因"两套口径"翻车三次（前瞻窗口、聚类 t、本轮 PC 的 z 标准化作用域）
⇒ **再留一次靠约定的同源，第四次翻车只是时间问题。**

#### ⚠️ 裁决前必须先补的空白：「共振强度」**目前没有单位定义**

文档「测量权」写的是"共振强度（**连续量**、不硬分组、不输出名单）"，但**从未定义它测量的是什么**：

| 候选单位 | 含义 | 问题 |
|---|---|---|
| **群**对风格的共振 | 需要语义链先存在 | 与 §2.2「定义权归语义」一致 ✅ |
| **对**的共振强度 | 8,515 维 | 不可读，"连续量"失去意义 |
| **全市场**共振水平 | 另一个对象 | 与"链"无关 |

⇒ **"要不要风格调整"的答案会随单位而变**。**裁决测量层之前必须先钉死单位**（建议：群）。

### 11.2 三分类改用**检验版**（替代 §4 的极差拍系数）

研究员正确指出："把二元门槛换成三分类 = 把一个任意参数换成三个。" **正解不是拍系数，而是换成有零分布的检验。**

| 类别 | 判据 | 本批数据 | 纯噪声期望 |
|---|---|---:|---:|
| **结构** | **Cochran Q 同质性检验** p > 0.05（Fisher-z 变换，df=2） | **45** | **11**（5% 水平）⇒ **超额 34 = 真结构证据** |
| **新生** | 不同质 **且** 严格单调递增（在 z 上）**且** 每级增量 > 自身 SE | **33**（目测单调 77） | 36（1/6）⇒ 超额 41 |
| **衰减** | 不同质 且 严格单调递减 | 12 | — |
| **闪烁** | 其余 | 127 | — |

**实现细节（可直接编码）**：

```python
z = np.arctanh(r)                 # Fisher-z，需 clip(r, -0.999, 0.999)
w = n - 3                         # 各段权重（段长 486/484/666 ⇒ w = 483/481/663）
zbar = (z * w).sum() / w.sum()
Q = (w * (z - zbar)**2).sum()      # df = 2
p_hom = np.exp(-Q / 2)             # ⚠️ df=2 时卡方生存函数有精确闭式 ⇒ 不需要 scipy
SE_step = np.sqrt(1/w[i] + 1/w[j]) # 每级增量的噪声锚点（实测 0.06）
```

**要点**：

1. **锚在零分布上，不锚在门槛上** —— 报告方式改为"**实测 45 对 vs 噪声期望 11 对**"，
   而不是"45 对稳定"；
2. **每级噪声锚点不是拍的**：由 `SE(Δz)` 推出（研究员的"2×SE 起步"可由此得到，无需另定）；
3. **旧极差规则偏松**：极差 ≤0.13 给 67 对，其中 **22 对被 Q 判为不同质**；
4. ⚠️ **AI 自己的第一版趋势检验有缺陷，值得研究员注意**：`c=(−1,0,1)` 的线性对比
   **只看首尾**（`z₃−z₁`，中间权重 0）⇒ **它不是单调性检验**（会给出 119 对"显著趋势"，
   其中含非单调对）。**3 点等距的线性对比天生忽略中间点**——判"新生"必须在 z 上**另加严格单调条件**。

### 11.3 🔴 群级零分布**必须按 L1 分层抽取**（研究员与 AI 的初版方案都漏了）

实测背景：**同 L1 的残差共振显著高于跨 L1**（K=1 存活 **74% vs 27%**）。

⇒ 若零分布是"从 131 行业**全局**随机抽同规模群"，则**主要成员落在一级内部的候选链会轻松过关** ——
它赢的是 **L1 背景**，不是"链"。

**修法**：零分布按候选链的 **L1 构成分层抽取**（候选链在 L1 上有 `{A:2, B:3, C:1}`，就从 A 抽 2、B 抽 3、C 抽 1）。
**这是一个真实的假阳性来源，不修则 §5.3 的判据被系统性放宽。**

### 11.6 `mainline` 的 `status_note` **硬约束**

同意研究员的补充（`observational` 的既有语义是"证据不足"，而 `mainline` 的问题是"方法被判错"，

### 11.7 三项次级注意事项

| # | 事项 | 说明 |
|:--:|---|---|
| 1 | **带符号 r** 的副作用 | 若群级统计量改用**群级 PC1 方差占比**，注意**它对群规模敏感**（群越大占比越高）⇒ 零分布必须**严格 size-matched**，否则大群自动显著 |
| 2 | 研究员查的 matmul 警告 | 接受结论（数据 0 NaN/0 零方差，警告来自投影矩阵乘法的数值边界）。**但建议把该自检写成代码**（项目已有 `tests/selftest.py` 惯例）—— **"数据没问题"这句话本身也要可复跑** |
| 3 | 🔴 **调整后状态量的数据探针** | 若测量层采纳调整值，状态量就部分成为**因子面板的函数** ⇒ **面板故障会静默改变状态量**（退化到原始值或变垃圾）。项目刚为宽度建了 `BREADTH_ZERO` 探针防静默事故 ⇒ **任何风格调整后的状态量必须配同类探针**，否则是把一个新的数据风险引进日报的核心状态量 |
