> **来源**：`docs/plan/chain-clustering-review.md` §7（"必须钉死规格"由建议升级为强制）与 §11.5（六项 → 七项）。
> **作用**：两套实现对拍的**唯一依据**。任何实现（研究员 / AI / 未来的链验证管道）必须按本页取值重跑。
> **验收标准**：**两套实现必须【逐对一致】，不是"约等于"。差 1~2 对就是口径没锁死的信号，不是容差。**
> **锁定日期**：2026-10-06（第 1 版；先验名单锁定后更新 ⑦ 并重跑全表）

## ② beta 剥离

| 用途 | 口径 |
|:--|:--|
| **选对**（全样本） | **全样本剥一次**：对整个面板回归 `[1, mkt]`，残差算全样本相关 |
| **分段（三段稳定性）** | **每段各自重剥 beta** ⇒ 这是 **167 口径**（全样本剥一次则得 170） |
| 回归设计 | 设计矩阵 `[1, mkt]`，`np.linalg.lstsq`（与 `polyfit` 交叉验证一致） |
| 段界 / 段长 | 2020-01-01~2021-12-31（**486**）／2022-01-01~2023-12-31（**484**）／2024-01-01~2026-09-30（**666**） |

⚠️ 167 与 170 **都是合法规格**，本页选 167（分段剥）是因为分段剥更贴近"每段独立估计"的语义。
**两种口径不得混用** —— 这正是本页存在的理由。

## ③ 残差标准化

| 项 | 取值 |
|:--|:--|
| 相关系数计算 | **不做标准化**（Pearson 相关尺度不变，标准化与否不影响任何 r） |
| PC/SVD 诊断 | **必须声明作用域**：z 标准化在**全样本**做还是**段内**做 ⇒ 这是 19 vs 16 差 3 对的根源 |

## ④ SVD / PC 相关

| 项 | 取值 |
|:--|:--|
| 矩阵 | 残差的**相关阵**（= 标准化后协方差阵） |
| 定位 | **辅助诊断，不作判据**（review §5.2：无肘部 / 无经济身份 / 吸收真链） |
| 存活率分母 | 必须同时声明是"选中对"还是"稳定对"（29 vs 19 的另一半差） |

## ⑤ 存活 / 分类判据

| 代 | 判据 | 状态 |
|:--|:--|:--|
| **旧（已作废）** | 选对 = 全样本 \|r\| ≥ 0.40；判稳 = 三段 \|r\| ≥ 0.30（= 0.75·θ 相对规则）；极差 ≤ 0.13 | ⛔ 三分类旧计数作废 |
| **现行（检验版）** | 结构 = **Cochran Q 同质性检验 p > 0.05**（Fisher-z，df=2，闭式 `P=exp(−q/2)`） | ✅ |
| | 新生 = 不同质 & z **严格单调递增** & 每级增量 > `SE(Δz)=√(1/wᵢ+1/wⱼ)`，`w=n−3`（实测锚点 **0.06**） | ✅ |
| | 衰减 = 不同质 & z **严格单调递减**（**不设 SE 门槛**，见下） | ✅ |
| | 闪烁 = 其余 | ✅ |

> 🔴 **规格钉死（2026-10-06 实测）**：给"衰减"也加 SE 门槛 ⇒ 7 对；不设 ⇒ **12 对**（与 review §11.2 表一致）。
> 差的 5 对全是"严格递减但降幅未超噪声"（如 `[0.587, 0.503, 0.478]`）。
> **不对称的理由**：衰减的处置是"拒"（判据从宽无害），新生有转正路径（判据从严）。
> ⚠️ 实现见 `src/evaluation/inference.py::classify_three_segment`（唯一实现）；
> 测试 `tests/test_eval_inference.py::TestCochranQThreeSegment` 锁住全部四格。

## ⑥ 分母（各口径的基线集合）

| 集合 | 数量 |
|:--|---:|
| 选中对（全样本 \|r\| ≥ 0.40） | **217**（同 L1 108 / 跨 L1 109） |
| 旧判稳（三段 ≥0.30） | **167**（跨 L1 **78**） |
| 旧极差 ≤ 0.13 | **67**（其中 Q 判不同质 **22**） |
| 检验版：结构 / 新生 / 衰减 / 闪烁 | **45 / 33 / 12 / 127** |
| 结构类 L1 分解（首次产出） | 同 L1 **25** / 跨 L1 **20** |

**噪声期望**：结构类在 5% 水平下的纯噪声期望 = 217 × 0.05 ≈ **11** ⇒ 超额 **+34** 对才是真结构证据。
⚠️ **报告纪律**：一律写「实测 X 对 **vs 噪声期望 Y 对**」，不写「X 对稳定」。
