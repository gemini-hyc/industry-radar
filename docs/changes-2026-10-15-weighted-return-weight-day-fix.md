# 变更记录 2026-10-15 · 行业加权收益「权重取值日」缺陷修复

> 关联研究：`research/prosperity/05ah_加权口径缺陷与事件研究复验.md`
> 性质：**修正性**（原数据偏大且偏差非等幅）· 影响 production 数据 + 日报 + 全部含「超额」的研究

---

## 1. 根因

`scripts/compute_weighted_returns.py`（修复前 128/135 行）：

```python
weighted_pct = Σ(pctChg_t × circ_mv_t) / Σ(circ_mv_t)
#                            ↑ 当日收盘市值   ↑ 又是当日
```

用**当日收盘后**才知道的市值去加权**当日**涨跌幅 ⇒ 系统性把权重偏向当天涨得多的股票。
数学偏差 ≈ **+Var_w(r)**（行业内按市值加权的收益方差），实测约 **+6bp/日 ≈ +15%/年**。

**要害不在「有多大」，而在「不是常数」**：Δ行业 = Var_w(r_行业)，取决于行业内部离散度。
低估值/老经济/低波动行业离散度小 ⇒ 虚增更少 ⇒ 在 `EX = R − mkt` 里**不抵消**，其超额被系统性压低。

正确口径的经济含义：t−1 收盘按当时市值建仓，持有到 t 收盘，当日组合收益恰为
`Σ w_{t-1} · r_t`，`w_{t-1} = circ_mv_{t-1} / Σ circ_mv_{t-1}` —— 这才是可实现的持有收益。

### 3.5 🔴 附带发现：研究侧「市场基准」也有同一个偏差

行业收益再聚合成市场序列时，用**今日** `circ_mv` 加权**今日** `weighted_pct`，是同一错误的第二层：

| 基准构造（都基于**修复后**的行业收益） | 日均偏离全指 |
|---|---|
| `Σ w_t · r_t`（旧做法） | +0.0324pp |
| `Σ w_{t-1} · r_t`（正确） | **+0.0104pp（年化 +2.5%）** |

⇒ 先把收益表修好，再把基准也改成前一日加权，残余偏离降到 +2.5%/年，可由
「中证全指 = 自由流通市值加权 + 剔除 ST/暂停上市」与我们「流通市值加权 + 含 ST」的
**成分差异**解释，不再是系统性算术偏差。

> ⛔ 结论：**凡是引用 `weighted_pct` 做「超额」的研究，两处都要改**（收益表已改；研究脚本内的基准需各自复核）。

### 3.6 修正幅度的行业异质性（为什么必须修）

逐行业日均虚增（旧−新）：最小 **−0.0235pp**，中位 **+0.0485pp**，最大 **+0.1192pp**
⇒ 极差 **0.1427pp/日 ≈ 34.8pp/年**，且在 `EX = R − mkt` 中**不抵消**。

- 新表 vs 成员快照：**应覆盖 213,574 格，实际 213,574 格，零缺零余**

据此处修正 `tests/test_invariants.py::TestGridCompleteness`：

## 7. 遗留 / 影响到的结论

1. **01~09 号报告的「超额」数字不可再直接引用**，需按新表 + 前一日加权基准重跑（方向多半保留、幅度会变）。
   已知修正量级参考（`05ag/05aj`）：PB 低估事件 120 日超额中位 −3.33% → **≈ −1.4%**。
2. 研究侧脚本凡自行构造市值加权市场序列的地方（`05*` 系列等），需同步把
   `Σ circ_mv_t · r_t` 改为 `Σ circ_mv_{t-1} · r_t`（约再 −0.022pp/日）。
3. `circ_mv` 输出列仍是当日市值（size 语义），**未**因本次修复改变。
4. 新式的尤须注意：Composition changes 会让旧历史值与新重建值不同（§4），
   对「历史某一天的绝对值」类引用要注明口径日期。
